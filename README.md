## 🎯 Objectif du cours

Explorer comment les approches de la psychologie de la perception et de la cognition peuvent inspirer, contraindre et critiquer le développement de systèmes d’intelligence artificielle (IA), en mettant l'accent sur l’IA générative, les fondements théoriques, les principes de base et les applications concrètes.
